# Chojema Image+

Windows와 macOS용 가볍고 빠른 이미지 뷰어입니다.

[English](README.en.md)

## 기능

- **목록 화면**: 왼쪽 폴더 트리(즐겨찾기·최근 폴더·위치)에서 폴더를 고르면 오른쪽에 하위 폴더와 썸네일이 나열됩니다. 하위 폴더를 클릭하면 그 안으로 들어가고, 사진을 끌어다 놓으면 그 폴더로 옮기거나 복사합니다.
  - 사진이 수만 장인 폴더도 바로 열리고, 화면에 보이는 썸네일부터 만들어지며 나머지는 미리 준비됩니다.
  - 다른 프로그램에서 폴더의 파일을 더하거나 지우면 목록이 자동으로 갱신됩니다.
  - 이름·수정한 날짜·크기순 정렬, 썸네일 크기 조절
  - Ctrl(⌘)·Shift + 클릭으로 여러 장 선택, 선택한 이미지만 넘겨 보기
- **목록에서 정리·검색**: 새 폴더 단추 또는 빈 공간의 오른쪽 클릭 메뉴에서 현재 폴더 안에 새 폴더를 만듭니다(Ctrl/⌘ + Shift + N). 생성 후 새 폴더가 선택됩니다.
  - 이름 입력란에는 선택한 하위 폴더명, 선택이 없으면 현재 폴더명이 미리 입력되며 바로 바꿔 쓸 수 있습니다.
  - 이미지 한 장을 선택하고 F2 또는 오른쪽 클릭 → 이름 바꾸기로 실제 파일 이름을 바꿉니다. 하위 폴더도 오른쪽 클릭으로 이름을 바꿀 수 있습니다. 같은 이름이 있으면 덮어쓰지 않으며, 짝 파일도 선택해서 함께 바꿀 수 있습니다. Ctrl/⌘ + Z로 되돌립니다.
  - 검색창(Ctrl/⌘ + F)은 현재 폴더의 파일·하위 폴더 이름을 즉시 좁힙니다. 대소문자를 구분하지 않으며 Esc나 지우기 단추로 해제합니다. 검색 결과 안에서만 모두 선택·이동·복사합니다. 이중 창의 검색은 각각 독립적입니다.
  - 이미지 파일 복사(Ctrl/⌘ + C)·잘라내기(Ctrl/⌘ + X) 후 대상 폴더에서 붙여넣기(Ctrl/⌘ + V)를 합니다. Finder·탐색기의 파일 클립보드와 연동하며, 앱 안에서 붙여넣을 때 기존 짝 파일·충돌 처리와 되돌리기를 사용합니다. 잘라내기는 붙여넣기가 성공할 때 이동합니다. 같은 폴더에 복사해서 붙여넣으면 이름을 바꿔 복사본을 만들 수 있습니다. macOS에서는 Finder에서 복사한 파일을 ⌘ + Option + V로 이동할 수도 있습니다.
- **보기 화면**: 썸네일을 더블클릭하거나 Enter를 누르면 크게 봅니다. Esc를 누르면 목록으로 돌아갑니다.
  - 목록으로 돌아오면 각 창의 스크롤 위치를 복원하고 보고 있던 사진을 화면 안에 표시합니다.
  - 창에 맞춤, 실제 크기, 확대·축소, 끌어서 이동
  - 90도 회전(보기 전용, 원본 파일은 바뀌지 않음), 전체 화면
  - 사진 상세 정보: 오른쪽 패널(작은 창에서는 하단)에 파일 정보, 촬영 시각·카메라·렌즈·노출·ISO 등 주요 EXIF와 GPS 좌표·고도를 표시합니다. 정보 단추나 I로 열고 닫으며, 파일에 저장된 정보만 읽습니다.
- **동영상**: 목록에 이미지와 함께 동영상 썸네일(재생 표시)이 나타나고, 크게 보면 바로 재생됩니다.
  - 재생·일시 정지(Space), 5초 앞뒤로(Shift + → / ←), 소리 끄기(M)와 재생 막대의 탐색·음량 조절. 다른 파일로 넘기기·이동·복사·휴지통·이름 바꾸기는 이미지와 같습니다.
  - 편집·내보내기·나란히 비교·슬라이드 쇼는 이미지만 대상으로 합니다.
- **나란히 비교**: 썸네일 2~4장을 선택하고 비교 단추나 C를 누르면 나란히 봅니다.
  - 2장은 좌우·위아래, 3장은 가로 3칸, 4장은 2×2로 배치
  - 확대·이동을 모든 칸에 함께 맞추기(해상도가 달라도 같은 부분을 표시), 칸별 회전·닫기
  - 선택한 칸의 이미지를 이동(M)·복사(C)하는 별도 아이콘. 이동하거나 되돌린 뒤에도 파일 경로와 이름을 갱신하고 확대 상태를 유지합니다.
- **다른 폴더로 이동·복사**: 선택한 썸네일을 왼쪽의 폴더·즐겨찾기·최근 폴더나 경로 표시줄로 끌어다 놓거나, 이동·복사 단추(M)로 폴더를 고릅니다.
  - 이동·복사 단추(M)에서는 작업 종류를 고르고, 별도 이동·복사 아이콘은 선택한 작업으로 확인합니다. 같은 이름의 파일이 있으면 이름 바꿔 둘 다 유지·덮어쓰기·건너뛰기 중에서 고릅니다.
  - 같은 이름의 짝 파일(RAW+JPEG, .xmp, 라이브 포토 동영상 등)도 함께 옮길 수 있고, 이름을 바꾸면 짝 파일도 같은 이름으로 바뀝니다.
  - 덮어쓴 기존 파일은 휴지통으로 보내고, 방금 한 작업은 Ctrl(⌘) + Z로 되돌립니다.
- **이중 창**(F6): 목록을 좌우나 상하 두 창으로 나눠 폴더 두 개를 함께 엽니다.
  - 한 창의 썸네일을 다른 창으로 끌어다 놓거나 M을 누르면 반대쪽 창의 폴더로 이동·복사합니다.
  - 각 창의 이동·복사 아이콘으로 선택한 이미지를 반대편 폴더로 옮기거나 복사할 수 있습니다.
  - Tab으로 창을 바꾸고, 왼쪽 폴더 트리와 즐겨찾기는 활성 창(파란 밑줄)에 열립니다.
- **휴지통으로 이동**: 선택한 이미지를 휴지통 단추, Delete 키(맥은 ⌘ + Backspace)나 오른쪽 클릭 메뉴로 휴지통에 보냅니다. 짝 파일도 함께 보낼 수 있고, 보기 화면에서는 보고 있는 사진을 지운 뒤 다음 사진으로 넘어갑니다.
- **오른쪽 클릭 메뉴**: 크게 보기, 나란히 비교, 다른 폴더로 이동·복사, Finder(탐색기)에서 보기, 휴지통으로 이동
- **슬라이드 쇼**(S 또는 재생 단추): 폴더와 하위 폴더 포함 여부, 순서(목록 정렬 순서 / 무작위), 창보다 작은 이미지(원래 크기 / 확대)와 큰 이미지(축소 / 원래 크기), 넘김 간격, 화면 표시(현재 날짜와 시각, 파일 이름, 순서 번호), 반복, 전체 화면을 고릅니다. 설정은 기억됩니다.
  재생 중 마우스를 움직이거나 Tab을 누르면 이전·다음, 일시 정지·다시 재생, 이미지 폴더로 이동, 전체 화면, 마침 메뉴가 나타납니다. 메뉴는 잠시 뒤 자동으로 숨겨지며, 일시 정지하거나 메뉴를 조작하는 동안은 유지됩니다. 이미지 폴더로 이동하면 슬라이드 쇼를 마치고 현재 보이는 파일이 들어 있는 폴더를 열어 그 파일을 선택합니다.
- **이미지 편집**(보기 화면의 편집 단추, E 또는 오른쪽 클릭): 90° 회전, 좌우·상하 뒤집기, 자르기(자유·원본 비율·1:1·4:3·3:2·16:9와 세로 비율), 크기 변경(긴 변 / 비율), 두께와 색상을 정한 테두리. 복사본(이름_edit)으로 저장하거나 원본을 덮어씁니다(원본은 휴지통으로).
- **다른 형식으로 내보내기**(Ctrl/⌘ + E 또는 오른쪽 클릭): JPEG, PNG, WebP, AVIF, HEIC(macOS), TIFF, BMP
  - 품질, 크기(원래 크기 / 긴 변 기준 / 비율), 촬영 정보(유지 / 위치 정보만 제거 / 모두 제거), 투명 부분 배경색
  - 저장 위치(원본 폴더 안의 하위 폴더 / 같은 폴더 / 반대쪽 창 / 다른 폴더)와 파일 이름 뒤에 붙일 글자
  - 사진의 회전 정보는 픽셀에 반영되고, 원본은 바뀌지 않습니다. 같은 이름이 있으면 묻습니다.
- 폴더 즐겨찾기(지정·해제, 이름 바꾸기, 순서 변경)와 최근 폴더 목록
- 상단의 이전 폴더 버튼(Alt + ←, 맥은 ⌘ + [도 가능)은 방문했던 폴더로 돌아가며 선택과 스크롤 위치를 복원합니다. 상위 폴더 버튼과 별개이며 이중 창에서는 창마다 기록합니다.
- 끌어다 놓기, 여러 파일을 한꺼번에 열기, 이미지 파일 연결(더블클릭으로 열기)
- 설정: 화면 언어(시스템 설정 따르기 / 한국어 / English), 앱을 열 때 첫 화면(마지막으로 보던 폴더 / 빈 화면), 저장된 썸네일 지우기

## 지원 형식

| 형식 | Windows | macOS |
|---|:---:|:---:|
| JPEG, PNG, GIF, WebP, BMP, ICO, AVIF, SVG | ✓ | ✓ |
| TIFF | ✓ | ✓ |
| HEIC, HEIF | ✓¹ | ✓ |
| 동영상: MP4, M4V, MOV, WebM | ✓² | ✓² |

¹ Windows에 Microsoft Store의 **HEIF 이미지 확장**과 **HEVC 비디오 확장**이 설치되어 있어야 합니다. Windows 사진 앱에서 HEIC가 열리면 이미 설치된 것입니다.

² 재생 가능 여부는 동영상 코덱에 따라 다릅니다. H.264·HEVC·VP9 등 시스템 웹 보기가 재생하는 코덱을 지원하며(Windows의 HEVC는 HEVC 비디오 확장 필요), 재생할 수 없는 파일은 안내 문구를 표시합니다.

## 설치

[Releases](../../releases) 페이지에서 내려받습니다.

- **Windows**: `ChojemaImagePlus-<버전>-windows-x64-setup.exe`
- **macOS**: `ChojemaImagePlus-<버전>-macos-universal.dmg` (Apple Silicon, Intel)

요구 사항: Windows 10 이상(WebView2), macOS 12 이상

현재 설치 파일에는 코드 서명이 없어 처음 실행할 때 경고가 나타날 수 있습니다.

- **Windows**: SmartScreen 창에서 **추가 정보 → 실행**을 누릅니다.
- **macOS**: 앱을 처음 열 때 차단되면 **시스템 설정 → 개인정보 보호 및 보안**에서 **그래도 열기**를 누릅니다.
