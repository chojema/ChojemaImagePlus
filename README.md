# Chojema Image+

Windows와 macOS용 가볍고 빠른 이미지 뷰어입니다.

[English](README.en.md)

## 기능

- **목록 화면**: 왼쪽 폴더 트리(즐겨찾기·최근 폴더·위치)에서 폴더를 고르면 오른쪽에 썸네일이 나열됩니다.
  - 이름·수정한 날짜·크기순 정렬, 썸네일 크기 조절
  - Ctrl(⌘)·Shift + 클릭으로 여러 장 선택, 선택한 이미지만 넘겨 보기
- **보기 화면**: 썸네일을 더블클릭하거나 Enter를 누르면 크게 봅니다. Esc를 누르면 목록으로 돌아갑니다.
  - 창에 맞춤, 실제 크기, 확대·축소, 끌어서 이동
  - 90도 회전(보기 전용, 원본 파일은 바뀌지 않음), 전체 화면
- **나란히 비교**: 썸네일 2~4장을 선택하고 비교 단추나 C를 누르면 나란히 봅니다.
  - 2장은 좌우·위아래, 3장은 가로 3칸, 4장은 2×2로 배치
  - 확대·이동을 모든 칸에 함께 맞추기(해상도가 달라도 같은 부분을 표시), 칸별 회전·닫기
- 폴더 즐겨찾기(지정·해제, 이름 바꾸기, 순서 변경)와 최근 폴더 목록
- 끌어다 놓기, 여러 파일을 한꺼번에 열기, 이미지 파일 연결(더블클릭으로 열기)
- 설정: 앱을 열 때 첫 화면(마지막으로 보던 폴더 / 빈 화면), 저장된 썸네일 지우기

## 지원 형식

| 형식 | Windows | macOS |
|---|:---:|:---:|
| JPEG, PNG, GIF, WebP, BMP, ICO, AVIF, SVG | ✓ | ✓ |
| TIFF | ✓ | ✓ |
| HEIC, HEIF | ✓¹ | ✓ |

¹ Windows에 Microsoft Store의 **HEIF 이미지 확장**과 **HEVC 비디오 확장**이 설치되어 있어야 합니다. Windows 사진 앱에서 HEIC가 열리면 이미 설치된 것입니다.

## 설치

[Releases](../../releases) 페이지에서 내려받습니다.

- **Windows**: `ChojemaImagePlus-<버전>-windows-x64-setup.exe`
- **macOS**: `ChojemaImagePlus-<버전>-macos-universal.dmg` (Apple Silicon, Intel)

요구 사항: Windows 10 이상(WebView2), macOS 12 이상

현재 설치 파일에는 코드 서명이 없어 처음 실행할 때 경고가 나타날 수 있습니다.

- **Windows**: SmartScreen 창에서 **추가 정보 → 실행**을 누릅니다.
- **macOS**: 앱을 처음 열 때 차단되면 **시스템 설정 → 개인정보 보호 및 보안**에서 **그래도 열기**를 누릅니다.

## 단축키

**목록 화면**

| 동작 | 키 |
|---|---|
| 썸네일 이동 / 범위 선택 | 방향키 / Shift + 방향키 |
| 크게 보기 | Enter, Space, 더블클릭 |
| 모두 선택 | Ctrl(⌘) + A |
| 선택한 2~4장 나란히 비교 | C |
| 상위 폴더 | Backspace, Alt + ↑ |
| 새로 고침 | F5 |
| 사이드바 숨기기·보이기 | Ctrl(⌘) + B |
| 설정 | Ctrl(⌘) + , |

**보기 화면**

| 동작 | 키 |
|---|---|
| 목록으로 돌아가기 | Esc |
| 다음 / 이전 이미지 | → ↓ PageDown Space / ← ↑ PageUp Backspace |
| 처음 / 마지막 이미지 | Home / End |
| 확대 / 축소 | + / - , Ctrl(⌘) + 휠, 트랙패드 핀치 |
| 창에 맞춤 / 실제 크기 | 0 / 1, 더블클릭 |
| 오른쪽 / 왼쪽 회전 | R / L |
| 전체 화면 / 나가기 | F, F11, Enter / Esc |
| 즐겨찾기·최근 폴더 목록 | Ctrl(⌘) + B |

**비교 화면**

| 동작 | 키 |
|---|---|
| 목록으로 돌아가기 | Esc |
| 확대 / 축소 | + / - , 휠, 트랙패드 핀치 |
| 모두 창에 맞춤 / 모두 실제 크기 | 0 / 1 |
| 확대·이동 함께 맞추기 켜기·끄기 | S |
| 좌우 / 위아래 배치 (2장) | V |
| 다음 칸 선택 | Tab |
| 선택한 칸 회전 / 닫기 | R, L / Delete |
| 전체 화면 | F |

**공통**

| 동작 | 키 |
|---|---|
| 파일 열기 / 폴더 열기 | Ctrl(⌘) + O / Ctrl(⌘) + Shift + O |
| 현재 폴더 즐겨찾기 지정·해제 | Ctrl(⌘) + D |
| 즐겨찾기 1~9번 폴더 열기 | Ctrl(⌘) + 1~9 |

마우스 휠은 이미지가 창보다 클 때 화면을 이동하고, 그렇지 않을 때 이전·다음 이미지로 넘깁니다.

## 개인정보

네트워크에 접속하지 않으며 어떤 정보도 수집하거나 전송하지 않습니다. 즐겨찾기, 최근 폴더 목록, 설정은 이 컴퓨터의 앱 설정 폴더에, 썸네일은 앱 캐시 폴더에만 저장됩니다.
